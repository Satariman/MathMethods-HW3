Требуется Python 3.13.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Перед запуском выполните в ноутбуке ячейку сохранения модели: она создаст model.joblib, config.json и test.csv.

st.cache_resource используется для модели, потому что это один общий ресурс, который не нужно заново читать с диска при каждом действии. st.cache_data используется для таблиц и вычисленных вероятностей. Streamlit безопасно кэширует их как данные. Без joblib.load выполнялся бы при каждом изменении слайдера.
